# Sunrise Sail Prototype

Sunrise Sail is a lightweight mobile-first prototype for a daily sailing route game. Each run uses a manually configured "day" with simple sailing conditions like wind, temperature, waves, and current strength.

## MVP

- One short course
- One boat
- Manually defined daily conditions
- Hazards and checkpoints
- Finish timer
- Mobile-friendly controls

## Run

Open `index.html` in a browser.

## Files

- `index.html` - app shell
- `styles.css` - mobile-first presentation
- `game.js` - gameplay loop and simple sailing model
